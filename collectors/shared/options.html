LOOP Activity Collector

Reports the shape of your work so LOOP can find what you repeat.

From the LOOP console: System → Observation sources → Connect a browser. The token is shown once.

Matched against the whole URL. Applied here and re-checked on the server, so an out-of-date extension cannot keep reporting an excluded site.

What is collected
  • The application, the kind of action, and what sort of object it acted on.
  • The names of fields you filled — never what you typed into them.
  • A hash of copied text, so LOOP can tell that a value moved from one application to another without ever receiving the value.
What is not collected
  • Page content, message bodies, field values, passwords, or screenshots.
  • Anything at all while paused, or on a site you have excluded.

Revoking this source in the console invalidates the token and deletes every event it reported.
